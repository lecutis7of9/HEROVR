# HERO VR v0.0.5 - Made by Agent Mulder

First public HERO VR release: VR for Marvel's Spider-Man 2 (Steam, Spider-Man2.exe 2.810.0.0), with the HERO VR launcher.

**Download:** `HERO-VR-Launcher-0.0.5.zip` (below). Extract it to e.g. `C:\HERO-VR`, double-click **HERO VR Launcher.cmd**, press **Build** once, then **PLAY VR**.

## New in 0.0.5
- Punch sensitivity FORGIVING (default) / MAX / 0.0.4 / STRICT: more punches land.
- HERO HEIGHT 1.00x-1.60x for big hero skins.
- Iron Man's beam cooldown is a ring on the right wrist.
- FLY: FAST is 40 m/s, plus a SUPERSONIC dash with a sonic boom.
- The mod's own sound effects, with SFX VOLUME.
- Damage probe and an experimental DAMAGE TEST (OFF by default).
- The HERO VR launcher: one window with PLAY VR, launch options, build, updates, revert and reports.

## Requirements
Windows 10/11 64-bit; Marvel's Spider-Man 2 on Steam, version 2.810.0.0; a PC VR headset with OpenXR (Virtual Desktop, Quest Link / Air Link or SteamVR). To build once: Visual Studio 2022/2026 "Desktop development with C++", Git for Windows, Python 3.11+.
