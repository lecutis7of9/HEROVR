# HERO VR 0.0.80

**EXPERIMENTAL.** New gameplay is in this release for both Classic and Performance. Story and window lighting work are still ongoing. If something feels off, your report (the launcher's Reports folder, or starting a session with *Record a report*) helps us fix it.

## What's new

**Both renderers, same new gameplay.** Classic (Original) and Performance both ship the 0.0.80 gameplay. Classic is the default: the 0.0.78-style full-resolution path (vr_aa ours, full eye size). Performance is the same build plus the 70% temporal-upscale marker, for a higher frame rate. The launcher label stays **Performance**. Pick the mode on the first screen; you can switch later.

**Eye jitter setting.** You can turn eye jitter on or off from the wrist / holo settings.

**Sprinting.** Sprint is in.

**Wall crawl, plus Game Wall Anims.** Climb and crawl on walls. The **Game Wall Anims** toggle uses the game's own wall-run / climb animations when you want them.

**Hand climb.** Reach up and climb with your hands.

**Flips on the left stick.** Left-stick flips are in.

**In the air: right stick up zips, right stick down heals.**

**Weblines.** Hold the grip to fire a webline. Weblines only work when you are standing, perched, or on a wall. A webline marker can be turned on or off (default on).

**One-hand web strike and two-hand yank.**

**Y in the air goes to the game.** This is the Sandman webzip (and other in-air Y the game asks for).

**Peter's camera and Miles's Prowler scanner.** Hold the left trigger at your left temple. The world scanner is unchanged.

**Stealth prompt pass-through.** When the game asks for a stealth / takedown input, that prompt is passed through.

**Prowler stash doors.** Open them with a right-stick click or a two-hand yank (L1+R1). This stash fix has not been tested in a headset.

**Build file check.** The launcher checks that the files in the folder belong together. Unzip this release into a **new empty folder**. Do not drop it over an old install.

## Known issues

- Sandman progression may stall.
- Far-edge aliasing is still there (not addressed in this release).
- The Prowler stash-door fix is untested in a headset. If a door still will not open, send a report and we will hotfix it.

## Install and update

Download **HERO-VR-Launcher-0.0.80.zip**, extract it into a **new empty folder**, and double-click **HERO VR Launcher.cmd**.

If you already have the HERO VR launcher (0.0.79 or earlier), open it and use **Check for Update**. It will offer 0.0.80.

Need an earlier release? On the first screen, *Use a previous version*.
