# HERO VR 0.0.81

**Hotfix for 0.0.80.** Everything else is the same as 0.0.80 (Classic and Performance, same gameplay).

## What's new

**WEBLINES toggle.** Hotfix: wrist holo toggle to turn weblines off if they interfere with swinging. Open the wrist holo, go to **VR SETTINGS > BODY AND VIEW > WEBLINES** and press it to switch **ON / OFF**. OFF means the grip Web Line gesture is fully skipped, so grip and swinging behave as if the feature was never there. It is ON by default and is remembered in `live.txt` (`webline_gesture = on` or `off`). The separate WEB LINE MARKER toggle is unchanged.

This hotfix has not been tested in a headset.

## Install and update

Download **HERO-VR-Launcher-0.0.81.zip**, extract it into a **new empty folder**, and double-click **HERO VR Launcher.cmd**.

If you already have the HERO VR launcher (0.0.80 or earlier), open it and use **Check for Update**. It will offer 0.0.81.

Need an earlier release? On the first screen, *Use a previous version*.

Spider-Man 2 only (SM1 is paused).
